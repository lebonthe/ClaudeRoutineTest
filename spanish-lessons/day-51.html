🎯 今日學習目標

學完今天的內容後,你能夠掌握 por 與 para 各自最核心的使用情境(por:原因/理由、經過的時間長度、交換/代價、透過的方式或路徑、代替某人;para:目的/目標、接收對象、期限、目的地、比較基準),並在常見的「一句話兩種介係詞都文法正確、但意思完全不同」的情境中,正確判斷該用哪一個。

🔍 拆解與超詳細細節(文法與字詞解密)

  • 最快的判斷口訣:por 回答「為什麼/怎麼做到的」,para 回答「為了什麼/給誰/到何時」。 Por 指向句子背後的「原因、途徑、代價」——是導致這件事發生的來源;Para 指向句子前方的「目的、接收者、終點」——是這件事所朝向的方向。可以想像 por 是一支箭「從後面推」,para 是一支箭「朝前面指」。
  • por 的五大核心用法,對話句都各示範了一種:
    1. 原因/理由:「por tu cumpleaños」(因為你的生日)——回答「為什麼買禮物」。
    2. 經過的時間長度:「por una hora」(達一小時之久)——單純描述動作持續的時間長度,不涉及截止時間點(截止時間點才輪到 para,見下)。
    3. 經過的空間/路徑:「por el centro」(經過市中心)——描述移動所「經過」的地方,而非「前往」的目的地。
    4. (對話中未出現,但常考)交換/代價:「Te doy 10 dólares por el libro.」(我用 10 美元跟你換這本書)——強調「以……作為交換」。
    5. (對話中未出現)代替某人做某事:「Trabajé por mi hermano ayer.」(我昨天代替我哥哥上班)。
  • para 的四大核心用法,對話句也各示範了一種:
    1. 接收對象:「para ti」(給你)——禮物最終要交給的人。
    2. 目的/目標(接不定詞):「para comprarlo」「para verte feliz」(為了買它/為了看你開心)——para + 原形動詞,是西語中表達「為了做某事」最常見、最基本的公式,初學者最早接觸的 para 用法之一。
    3. (對話中未出現)目的地:「Salgo para Madrid mañana.」(我明天動身前往馬德里)——強調「朝向」某個終點,與 por 描述「經過」的路徑形成對比。
    4. (對話中未出現)期限/截止時間點:「La tarea es para el viernes.」(這份作業的截止日是星期五)——與 por 的「經過的時間長度」形成鮮明對比:por una hora 講的是「花了多久」,para el viernes 講的是「什麼時候之前要完成」。
  • 對話裡最值得注意的一組對比:同一件事,por 和 para 分別回答了不同的問題。 B 問「¿Caminaste por el centro para comprarlo?」這句話裡 por 和 para 同時出現卻毫不衝突:por el centro 回答「走的路線經過哪裡」,para comprarlo 回答「這趟走路的目的是什麼」——一句話裡,por 交代途徑/過程,para 交代目的/方向,兩者分工明確,合起來才是完整的資訊。
  • 常見混淆陷阱:「lo hice por/para ti」意思完全不同。 「Lo hice por ti」(我這麼做是因為你/是為了[回應]你[的緣故、請求或情況])側重「你」是造成這件事發生的原因;「Lo hice para ti」(我這麼做是為了給你、是為了你[的利益])側重「你」是這件事最終要服務、受益的對象。中文翻譯經常兩者都能說成「為了你」,但西語裡動機來源(por)和服務對象(para)是兩個完全不同的邏輯位置,務必依語境判斷說話者真正要表達的是哪一種關係。

💡 文化或實用小撇步

西語教師常用的英語記憶口訣是把 para 的四大用法字首湊成 "PPPP"(Purpose 目的、Person receiving 接收者、Place [destination] 目的地、Period [deadline] 期限),而 por 則對應 "MRECT"(Motive/Reason 原因、Route 經過路徑、Exchange 交換代價、Cause/duration 持續時間、Trade-off/on behalf of 代替某人)之類的組合詞。與其死背落落長的規則清單,不如先記住一個最簡單的判準:如果整句話可以換句話說成「the reason is...」(原因是……)或「in exchange for...」(以……交換),多半該用 por;如果可以換句話說成「in order to...」(為了要……)或「intended for...」(打算給……),多半該用 para。

✍️ 1 分鐘互動練習題

  1. 填空題: 「Estudio español ___ (por/para) trabajar en Argentina el próximo año.」(我學西班牙文是為了明年能在阿根廷工作。)請選出正確的介係詞。
  2. 辨析題: 「Pasamos por Barcelona.」與「Vamos para Barcelona.」這兩句話,雖然中文都可能翻成跟「去巴塞隆納」有關,但兩者所描述的旅程性質有什麼關鍵不同?

🔑 今日練習題答案與解析

第 1 題答案: para。
解析:這句話描述的是學西班牙文這個行為「所要達成的目的」——為了將來能在阿根廷工作,屬於 para + 原形動詞的「為了做某事」核心公式,而非在回答「為什麼」這個原因(如果是回答「因為工作機會很多所以學西語」這種純粹的動機/原因,才會考慮 por)。

第 2 題答案: 「Pasamos por Barcelona」使用 por,意思是「我們『途經』巴塞隆納」——巴塞隆納只是行程中經過的一站,不是最終目的地,言下之意旅程還會繼續到別處;「Vamos para Barcelona」使用 para,意思是「我們『前往』巴塞隆納」——巴塞隆納本身就是這趟旅程的終點/目的地。同樣提到巴塞隆納,por 版本暗示它只是路過的中繼站,para 版本則明確指出它就是最終要抵達的地方。
