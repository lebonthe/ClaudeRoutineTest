西班牙文家教課 — 第131天:東西壞了與修理(Romper / Romperse / Estropearse / Funcionar / Arreglar)

複習:昨天(第 130 天)是第 126–129 天的複習與累積測驗(放、說、找、開關)。今天開始新主題:中文一句「壞了」就包辦的狀況——杯子破了、手機螢幕裂了、冷氣不能用、洗衣機故障、牛奶壞掉——西班牙文要依「怎麼壞」來選動詞。第 50 天的 estar + 過去分詞、第 57 天的意外 se、第 129 天的 encender / apagar 今天都會再出現。

🎯 Learning Goal 今日學習目標

學完今天,你能:(1) 用 romper / romperse / está roto 說東西「破了、斷了、裂了」;(2) 用 no funciona 和 estropearse(西班牙)/descomponerse(拉丁美洲)說東西「不能用、故障」;(3) 用意外的 se 說「(不是我故意的)它壞了」;(4) 用 arreglar 請別人修理,或說「我拿去修了」。核心判斷:看得到的破損 → romper;還在但不會動 → no funciona / estropearse。

📚 Vocabulary 單字

西班牙文中文說明
romper打破、弄斷、撕破規則變化(rompo, rompí, rompió),但過去分詞不規則:roto(✗ rompido)。玻璃、杯子、螢幕、紙、衣服、骨頭都可以。
romperse(自己)破掉、斷掉Se rompió el vaso. = 杯子破了。Me rompí el brazo. = 我手臂骨折了(身體部位用冠詞,不用 mi)。
estar roto/a是破的、壞掉的結果狀態(第 50 天):La pantalla está rota. 口語上有時也用在不能用的機器(La tele está rota),但嚴格說是「物理損壞」。
funcionar運作、能用規則 -ar 動詞:No funciona el wifi. 阿根廷口語常說 no anda;墨西哥口語也說 no sirve。
estropearse / estropeado故障、壞掉(西班牙)Se estropeó la lavadora. 也用在食物:La leche se ha estropeado.(牛奶壞了。)
descomponerse / descompuesto故障(拉丁美洲)變化和 poner 一樣:se descompuso、分詞 descompuesto。在西班牙則較常指「分解、腐爛」。
averiarse / la avería(機器、車子)故障/故障較正式,常見於車子、電梯、公共設施:El ascensor está averiado.(電梯故障。)
arreglar修理;也有整理、打點的意思日常最常用:¿Me lo puedes arreglar? 注意 arreglarse = 打扮、準備出門。
reparar / la reparación修理/維修比 arreglar 正式,常見於店家招牌、保固文件。
el técnico / el taller維修人員/修車廠、維修中心Llevé el coche al taller. = 我把車送去修車廠。

🧩 Grammar Point 文法重點(拆解與細節)

  • ① 先判斷「怎麼壞」。看得到的破損(碎、裂、斷、撕破)→ romper。外表完好但不會動 → no funciona,或 se estropeó / se descompuso / se averió。所以手機螢幕裂了是 Se me rompió la pantalla,手機開不了機是 El móvil no funciona 或 Se me estropeó el móvil。
  • ② 及物 vs. 反身:誰造成的?Rompí el vaso. = 我打破了杯子(我是主詞,承認是我做的)。Se rompió el vaso. = 杯子破了(只描述事件)。Se me rompió el vaso. = 杯子在我手上破了(不是故意的)——這就是第 57 天的意外 se:se + 間接受詞代名詞(me/te/le…)+ 動詞,動詞和「壞掉的東西」一致:Se me rompieron las gafas.(我的眼鏡壞了——gafas 是複數,所以用 rompieron)。
  • ③ 狀態用 estar + 過去分詞(第 50 天)。La ventana está rota. La lavadora está estropeada. El ascensor está averiado. 分詞要和名詞的陰陽性、單複數一致:las sillas rotas。記住 roto 和 descompuesto 是不規則分詞。
  • ④ 「拿去修」:llevar / mandar a arreglar。西班牙文沒有英文的 "have something fixed" 句型,最自然的說法是 Llevé el portátil a arreglar.(我把筆電拿去修。)或 Tengo que mandar a arreglar la bici.(我得把腳踏車送修。)
  • ⑤ 請人修:加間接受詞。¿Me lo pueden arreglar hoy?(你們今天可以幫我修好嗎?)——me = 為我,lo = 那東西(第 45 天的雙受詞代名詞)。
  • ⑥ 和第 129 天的連結。壞掉的燈:La luz no se enciende(燈開不起來)或 Se fundió la bombilla(燈泡燒掉了,西班牙;拉丁美洲常說 se quemó el foco)。

💡 文化或實用小撇步

  • 向飯店或房東反映問題時,開頭加 Perdone, …(不好意思)或 Mire, es que…(是這樣的……,第 111 天的 es que),語氣會比直接說 No funciona 客氣很多。
  • 在西班牙,打破東西時大家常說 ¡Uy, lo siento!,主人常回 No pasa nada(沒關係)。說 Se me rompió 比 Lo rompí 聽起來沒那麼嚴重——語言本身就幫你「降低責任」。
  • 拉丁美洲很多地方說手機「壞了」也會用 Se me dañó el celular(哥倫比亞、委內瑞拉等常見);dañar 在西班牙比較像「損害、傷害」。

✍️ Practice Prompt 練習題

  1. 翻成西班牙文(對飯店櫃檯說):「不好意思,淋浴設備不能用,而且檯燈壞了。今天可以有人來修嗎?」
  2. 選擇正確的動詞:Mi móvil se cayó al suelo y ahora la pantalla está ______.(a) estropeada (b) rota (c) funcionada
  3. 改成「不是故意的」說法:Rompí las gafas.
  4. 用西班牙文說:「我上週把筆電拿去修,但還是不能用。」

🔑 今日練習題答案與解析

  1. Perdone, la ducha no funciona y la lámpara está rota. ¿Puede venir alguien a arreglarlas hoy?——淋浴設備「不會動」→ no funciona;檯燈如果是摔破 → está rota(如果只是不亮,說 la lámpara no funciona / no se enciende)。兩樣東西都是陰性,所以 arreglarlas。
  2. (b) rota——掉在地上摔「裂」是物理損壞,用 romper 的分詞 roto,配合 pantalla(陰性)變成 rota。estropeada 是「不能運作」;funcionada 不存在這種用法。
  3. Se me rompieron las gafas.——意外的 se + me,動詞跟著 las gafas(複數)變成 rompieron。
  4. La semana pasada llevé el portátil a arreglar, pero todavía no funciona.(拉丁美洲:…llevé la laptop / la computadora a arreglar, pero todavía no funciona / sigue sin funcionar.)——llevar a arreglar = 拿去修;todavía(第 74 天)= 還、仍然;seguir sin + 原形 = 仍然沒有……(第 83 天的 seguir)。
