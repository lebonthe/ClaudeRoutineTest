西班牙文家教課 — 第七十七天:Tener 慣用語(tener hambre / frío / razón / ganas de)

複習(第一~七十六天):問候、國籍、數字與序數、時間表達(含昨天的 hace / desde)、家人與所有格、各類時態與語氣、受詞代名詞、反身與被動、por/para、常用動詞短語與固定介系詞等。今天補上一個日常會話極高頻、但尚未單獨教過的主題:用 tener 表達身體感受與狀態的慣用語。

🎯 今日學習目標

學完今天的內容後,你能夠用 tener + 名詞說出「我餓了、我渴了、我冷、我睏、我怕、你說得對、我想要……」等日常感受(Tengo hambre. Tengo frío. Tienes razón.),並且分辨它與英文 be + 形容詞的差別,以及它與天氣用的 hacer(Hace frío)有何不同。

🔍 拆解與超詳細細節(文法與字詞解密)

  • 核心概念:西語用「擁有」,中文/英文用「是」。英文說 I am hungry(我是餓的),西語說 Tengo hambre(我擁有飢餓)。所以這裡的 hambre、sed、frío 都是名詞,不是形容詞。請千萬不要說 Estoy hambre 或 Soy frío:前者名詞不能接 estar,後者 soy frío 的意思是「我這個人很冷漠」。
  • tener 的現在式變位(不規則):tengo / tienes / tiene / tenemos / tenéis / tienen。只有 yo 形是 -go,其餘詞幹 e 變 ie,nosotros 與 vosotros 維持 e(tenemos、tenéis)。今天對話出現的 tengo、tienes 都屬於這個表。
  • 程度用 mucho / mucha,不用 muy。因為後面是名詞,要用形容詞 mucho 並與名詞性別一致:mucha hambre(hambre 是陰性名詞,但以重音 á 開頭的單數名詞前會用 el,如 el hambre;用 mucha 修飾時仍依陰性寫 mucha hambre)、mucha sed、mucho frío、mucho calor、mucho sueño、mucho miedo。想說「有點」可用 un poco de:Tengo un poco de frío.
  • tener ganas de + 原形動詞:表示「很想做某事」,Tengo ganas de tomar un café. 如果後面接名詞則用 ganas de + 名詞(Tengo ganas de pizza.)。否定時是 no tener ganas de:No tengo ganas de salir.(我不想出門。)
  • tener razón 與 tener que 的差別:tener razón 是「你說得對」;tener que + 原形(第 59 天)是「必須」。反過來,「你錯了」是 No tienes razón. 或 Estás equivocado/a.
  • tener ... años 說年齡:西語問年齡用 ¿Cuántos años tienes?(你擁有幾年?),回答 Tengo veinticinco años. 不能用 ser。
  • 與天氣的 hacer 對比:描述「人」的感受用 tener(Tengo frío:我覺得冷),描述「天氣」用 hacer(Hace frío:天氣很冷),兩者主詞不同。所以對話最後一句先說 Hace frío(天氣冷),再說 tengo sueño(我睏)。另外,描述物品溫度則用 estar:El café está frío.(咖啡涼了。)
  • tener miedo de:後面接名詞或原形動詞都要加 de:Tengo miedo de volar.(我怕搭飛機。)在口語中 de 有時被省略,但書寫與考試建議保留。

💡 文化或實用小撇步

在西班牙或拉丁美洲,朋友約吃飯時很常聽到 ¿Tienes hambre?、¿Tienes ganas de salir?。想委婉拒絕邀約,可以說 Hoy no tengo muchas ganas.(今天不太想。)。另外,因為西班牙人晚餐很晚(常常九點以後),Tengo hambre 在下午六七點其實是相當常見的抱怨,此時可以說 Voy a tomar una tapa.(我去吃點小菜墊墊肚子。)。

✍️ 1 分鐘互動練習題

  1. 選詞填空題:「Es verano y hace mucho calor. Los niños ___ sed.」(A. están B. tienen C. son)
  2. 造句題:請用 tener 的慣用語說出:(1)「我朋友說得對。」(2)「我今天不想做功課(hacer la tarea)。」

🔑 今日練習題答案與解析

第 1 題答案:B(Los niños tienen sed.,孩子們渴了。)
解析:主詞是 los niños(他們),tener 的第三人稱複數是 tienen;「渴」是名詞 sed,不能搭 estar 或 ser。

第 2 題答案:(1)Mi amigo tiene razón.(若朋友是女生則 Mi amiga tiene razón.)(2)Hoy no tengo ganas de hacer la tarea.
解析:第一句主詞是第三人稱單數,所以用 tiene;第二句用 no tener ganas de + 原形動詞 hacer,ganas 前面不加 muchas 也可成立。
