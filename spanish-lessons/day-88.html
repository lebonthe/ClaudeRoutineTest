西班牙文家教課 — 第八十八天:介系詞後的人稱代名詞(mí / ti / conmigo / contigo)

複習:昨天學了詞幹變化動詞(quiero、puedo、pido)。今天學另一個很常用的小東西:介系詞(a、para、de、con、por……)後面的人稱代名詞,不能直接用 yo / tú(多數情況)。

🎯 今日學習目標

學完今天,你能:(1) 說出介系詞後的人稱代名詞形式——mí, ti, él/ella/usted, nosotros/as, vosotros/as, ellos/ellas/ustedes;(2) 正確使用特殊的合併形式 conmigo、contigo、consigo;(3) 知道例外:entre, según, excepto, incluso, salvo 後面用 yo / tú;(4) 用 a mí / a ti 來加強或釐清 me / te / le。

🔍 拆解與超詳細細節

  1. 基本規則:介系詞後面不用主詞代名詞(yo, tú),改用「介系詞格」代名詞。除了第一、第二人稱單數,其他人稱的形式跟主詞代名詞完全一樣:para él, para ella, para usted, para nosotros, para vosotros, para ellos。
  2. 兩個特殊形式:yo → mí、tú → ti。例:Es para mí. / Pienso en ti. / Hablan de ti.
  3. 為什麼 mí 有重音符號、ti 沒有?因為 mi(我的,所有格)和 mí(我,代名詞)長得一樣,需要區分;ti 沒有同形字,所以不需要。
  4. con 的例外:不說 con mí / con ti,而是合成一個字:conmigo、contigo。其他人稱照常:con él, con ella, con nosotros。
  5. consigo:當 con 後面的人就是句子的主詞(第三人稱)本人時,用 consigo:Ella lleva el paraguas consigo.(她把傘帶在身邊。)口語常見替代:con ella misma。
  6. 例外:entre, según, excepto, incluso, salvo, menos 後面要用主詞形式:entre tú y yo(不是 entre ti y mí)、según tú(依你說)、todos excepto yo(除了我之外的所有人)。
  7. a mí / a ti 的雙重功能:(a) 強調:A mí me gusta el té.(我就是喜歡茶。)(b) 對比:A mí me gusta el café, pero a ti te gusta el té.(c) 釐清 le / les:Le doy el libro a ella.。第 15 天學過的 gustar 句型,正是這個結構。
  8. 常見錯誤:(a) 不要說 para yo,正確是 para mí。(b) 不要說 con mí,正確是 conmigo。(c) 不要把 entre 後面也改成 mí/ti。

💡 文化或實用小撇步

西班牙人聊天時常說 ¿Y a ti?(那你呢?)、Por mí, vale.(我是無所謂/我同意。)、A mí, plim.(我才不在乎,口語)。想邀請別人時,最自然的是 ¿Quieres venir conmigo?。這幾句都不需要說出 yo 或 tú,聽起來更自然。

📝 例句

  • Este regalo es para ti. 這個禮物是給你的。
  • Ella siempre piensa en mí. 她總是想著我。
  • ¿Quieres cenar con nosotros? 你想跟我們一起吃晚餐嗎?
  • Sin ti, no puedo trabajar. 沒有你,我沒辦法工作。
  • Todos vienen excepto yo. 除了我,大家都來。
  • Según tú, ¿a qué hora empieza? 依你說,幾點開始?

🔑 今日練習題答案與解析

  1. mí / contigo / tú, yo:para 後面用介系詞格 mí;con + tú 合成 contigo;entre 是例外,後面維持 tú y yo。
  2. Sin ti, no voy.(sin 後面用 ti,不是 tú;ir 的 yo 形式是 voy。)
