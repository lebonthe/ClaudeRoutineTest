西班牙文家教課 — 第105天:「越來越……」「越……越……」Cada vez más / Cuanto más

複習:昨天(第 104 天)學了 cualquier / cualquiera(任何、隨便哪一個)。今天新主題:表達「漸漸變得更……」的 cada vez más / menos,以及「越……越……」的 cuanto más ... más ...。它們把第 46 天的比較級(más que)和第 84 天的 cada 接在一起用。

🎯 今日學習目標

學完今天,你能:(1) 用 cada vez más + 形容詞/副詞 說「越來越……」;(2) 用 cada vez menos 說「越來越不……、越來越少」;(3) 用 cuanto más ... (tanto) más ... 說「越……就越……」;(4) 分辨 cada vez más(隨時間變化)與 más y más(同樣可以,語氣更口語)。

🗣️ 核心對話 / 句子

Ana:Mi español es cada vez mejor. —— 我的西班牙文越來越好了。
米 埃斯帕尼奧爾 埃斯 卡達 貝斯 梅霍爾。(mǐ āi sī pà ní óu ěr āi sī kǎ dà bèi sī méi hò ěr.)
Luis:Sí, y hablas cada vez más rápido. —— 對,而且你說得越來越快。
西,伊 阿布拉斯 卡達 貝斯 馬斯 拉皮多。(xī, yī ā bù lā sī kǎ dà bèi sī mǎ sī lā pǐ dō.)
Ana:Cuanto más practico, más me gusta. —— 我越練習,就越喜歡。
誇恩多 馬斯 普拉克帝科,馬斯 梅 古斯塔。(kuā ēn dō mǎ sī pǔ lā kè dì kē, mǎ sī méi gǔ sī tǎ.)
Luis:Y cada vez tengo menos miedo de equivocarme. —— 我也越來越不怕犯錯了。
伊 卡達 貝斯 天哥 梅諾斯 米耶多 得 埃基沃卡爾梅。(yī kǎ dà bèi sī tiān gō méi nuó sī mǐ yē dō dé āi jī bò kǎ ěr méi.)

📚 單字

西班牙文中文說明
cada vez más + 形容詞 / 副詞越來越……cada vez más caro(越來越貴)、cada vez más tarde(越來越晚)
cada vez menos + 形容詞 / 名詞越來越不……/ 越來越少cada vez menos gente(人越來越少)
cada vez mejor / peor越來越好 / 越來越糟mejor、peor 本身已是比較級,前面不再加 más
cuanto más ... (tanto) más ...越……越……兩邊的「越」都可換成 menos:cuanto menos ..., más ...
cuantos / cuantas más + 名詞越多的……cuantos más amigos, más fiestas(朋友越多,派對越多)
poco a poco慢慢地、一點一點地近義說法,強調速度慢,不一定有比較的意思

🔍 拆解與超詳細細節

  1. cada vez 的字面意思:cada vez 是「每一次」(第 84 天學過 cada)。cada vez más 就是「每一次都更……」,所以自然帶出「越來越」的意思。
  2. 形容詞不變性別數:cada vez más 後面的形容詞照主詞變化:Las clases son cada vez más interesantes.(課越來越有趣。)但 más 本身不變。
  3. mejor / peor 是特例:說「越來越好」是 cada vez mejor,不要說 cada vez más mejor。同理 cada vez peor、cada vez mayor(越來越大/越年長)。
  4. cada vez menos 後面接名詞要配合:cada vez menos tiempo(時間越來越少);menos 修飾名詞時也不變性別。這點與 cuantos / cuantas 不同。
  5. cuanto más ... más ...:前半句的動詞通常用直陳式:Cuanto más estudias, más aprendes.(你越學越懂。)後半句的第二個 más 前面可以加 tanto 強調,但日常多半省略。
  6. cuanto 要配合名詞:接名詞時 cuanto 要變性別與單複數:Cuanta más agua bebes, mejor.(水喝得越多越好。)Cuantos más libros leo, más quiero leer.
  7. 不加重音:這裡的 cuanto 不是疑問詞(第 103 天的 ¿Cuánto? 有重音),所以不加重音符號。
  8. 與 cada vez más + 動詞的搭配:不用形容詞時,可以直接接動詞:Me gusta cada vez más.(我越來越喜歡。)Llueve cada vez menos.(雨越下越少。)

💡 文化或實用小撇步

  • 諺語:Cuanto más se tiene, más se quiere.(擁有的越多,想要的越多。)是西語國家常聽到的說法,用來形容人的貪心。
  • 新聞常見句型:西語新聞標題常寫 cada vez más personas ...(越來越多人……),看到這個句型就知道是在談趨勢。
  • 口語替代:想講得隨性,可以重複 más y más,意思相近。

✍️ 1分鐘互動練習題

  1. 填空:El invierno es ____ ____ más frío.(冬天越來越冷。)
  2. 用西語翻成:「你越早到,就越好。」(用 cuanto ... más/mejor)

🔑 今日練習題答案與解析

  1. cada vez:El invierno es cada vez más frío.(整句也可說 Cada vez hace más frío.)
  2. Cuanto más temprano llegues, mejor. 這裡 llegues 用虛擬式(第 27 天),因為說的是尚未發生、帶期望的事;mejor 是比較級,不加 más。
