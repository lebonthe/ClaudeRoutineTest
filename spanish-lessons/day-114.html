西班牙文家教課 — 第114天:Demasiado / Bastante / Suficiente / Poco(太多、相當、足夠、很少)

複習:昨天(第 113 天)學了 ver / mirar / oír / escuchar。今天新主題:第 1-113 天都沒有專門教過的「程度量詞」——demasiado(太)、bastante(相當/足夠)、suficiente(足夠的)、poco(很少)。重點是:它們修飾名詞時要跟名詞變性數,修飾形容詞或動詞時則不變。

🎯 今日學習目標

學完今天,你能:(1) 說出「太多/太貴」:demasiado;(2) 區分 bastante(相當多、還算)與「足夠」的兩種意思;(3) 判斷何時要變性數(demasiadas cosas)、何時不變(demasiado caro);(4) 區分 poco(很少、不太)與 un poco(一點點)。

🗣️ 核心對話 / 句子

Ana:Este restaurante es demasiado caro y hay demasiada gente. —— 這家餐廳太貴了,而且人太多。

Luis:Pues este otro es bastante barato y tiene bastantes mesas. —— 那這家就相當便宜,而且桌位也夠多。
普耶斯 艾斯特 奧特羅 艾斯 巴斯坦特 巴拉托 伊 帝耶內 巴斯坦特斯 梅薩斯(pǔ yē sī, āi sī tèi ào tè luó, āi sī bā sī tǎn tèi bā lǎ tuō, yī dì yē nèi bā sī tǎn tèi sī méi sǎ sī)

📚 單字

西班牙文中文說明
demasiado/a/os/as太多的;(副詞)太修飾名詞時變性數;修飾形容詞/副詞/動詞時固定為 demasiado
bastante(s)相當多的;足夠的;(副詞)相當、頗只有單複數變化(bastante / bastantes),沒有陰陽性變化
suficiente(s)足夠的形容詞,只有單複數;可放名詞前或後;副詞用法 suficientemente
poco/a/os/as很少的、不多的否定含意:「不太夠」;副詞 poco = 不太
un poco (de)一點點肯定含意:「有一些」;後接名詞時用 un poco de,名詞不變性數
de más / de menos多餘的 / 少了的例:Me dieron un euro de más.
sobrar / faltar剩下、多出 / 缺少用法像 gustar:Me falta tiempo.

🔍 拆解與超詳細細節

  1. 兩種詞性:這四個詞都能當「形容詞」(修飾名詞)或「副詞」(修飾形容詞、副詞、動詞)。當形容詞要跟名詞一致:demasiada gente, demasiados coches, pocas ideas。當副詞固定不變:Ella es demasiado joven. Ellas son demasiado jóvenes.(兩句都是 demasiado)。這是學習者最常錯的地方。
  2. demasiado = 超過合適程度(通常是負面):Hace demasiado calor.(太熱了。)Hablas demasiado.(你話太多。)注意:說「很好」不要用 demasiado,口語中某些地區會用 demasiado bueno 表示「太讚了」,但初學者先把它當作「太…」。
  3. bastante 有兩層意思:(a) 「相當、頗」:Es bastante difícil.(相當難。)(b) 「足夠」:No tengo bastante dinero.(我錢不夠。)判斷靠上下文;若要明確說「足夠」,用 suficiente。注意:作副詞的 bastante 通常比 muy 弱,表示「還蠻…」。
  4. suficiente 專指「足夠」:Hay suficiente comida para todos.(食物夠大家吃。)否定:No es suficiente. 副詞:No es suficientemente claro.(不夠清楚。)
  5. poco vs. un poco(很重要):Tengo poco tiempo.(我時間不多,幾乎沒有——偏負面);Tengo un poco de tiempo.(我有一點時間——偏正面,可以幫你)。同樣:Hablo poco español.(我西班牙文說得很差)vs. Hablo un poco de español.(我會說一點西班牙文)。
  6. un poco de + 不可數名詞(不變性數):un poco de agua, un poco de paciencia;可數複數名詞用 unos pocos / algunos:unos pocos amigos。
  7. muy vs. mucho 的搭配提醒:今天的詞是「程度」詞,muy 不能和它們連用(不說 muy demasiado);但可以說 demasiado poco(太少了)與 bastante poco(相當少)。
  8. 與 de más / de menos、sobrar / faltar 一起用:Sobran dos sillas.(多出兩把椅子。)Faltan tres euros.(還差三歐元。)主詞是「多出/缺少的東西」,動詞要跟它一致。
  9. 常見錯誤:(a) demasiados cara(形容詞/名詞不一致);(b) Ellas son demasiadas jóvenes(副詞誤變性數,應為 demasiado jóvenes);(c) 把 poco 和 un poco 混用,意思會相反;(d) bastantas(不存在,應為 bastantes)。

💡 文化或實用小撇步

  • 禮貌的「太多了,不用了」:被勸菜或勸酒時可以說 Gracias, ya es suficiente. 或 Es demasiado, de verdad.,語氣比單純 No 柔和。
  • 結帳與找零:店員說 Le faltan dos euros.(您還差兩歐元)或 Le sobran cinco.(多給了五元),會用 faltar / sobrar 的句型。
  • 委婉的負面評論:想委婉說「不太好」,西班牙人常說 No es suficientemente bueno 或 Es un poco caro(有點貴),比直接說 Es muy caro 緩和。

✍️ 1分鐘互動練習題

  1. 選 demasiado / demasiada / demasiados / demasiadas 填空:Hay ____ ruido y ____ personas; la sala es ____ pequeña.
  2. 用 poco 或 un poco 表達意思:(a) 「我只有一點點時間,可以聊五分鐘。」(b) 「我時間很少,沒辦法去。」
  3. 把句子改正:Las casas son demasiadas caras.

🔑 今日練習題答案與解析

  1. Hay demasiado ruido y demasiadas personas; la sala es demasiado pequeña. ruido 是陽性單數 → demasiado;personas 是陰性複數 → demasiadas;pequeña 是形容詞,前面的 demasiado 是副詞,固定不變。
  2. (a) Tengo un poco de tiempo; podemos hablar cinco minutos.(b) Tengo poco tiempo; no puedo ir. 有 un = 肯定「有一點」;沒有 un = 否定「幾乎沒有」。
  3. Las casas son demasiado caras. demasiado 在這裡修飾形容詞 caras,是副詞,不隨性數變化;caras 才與 casas 一致。
